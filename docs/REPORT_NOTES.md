## 4. The altermod bug, PMOS OFF readout precision and CSV digits (EXP-02, EXP-03, EXP-04)

**EXP-02 (project log, not a saved result file):** ngspice applies only the first parameter of a multi-parameter `altermod` line, so with `altermod pmos vth0 = .. toxe = .. ndep = .. u0 = .. xj = ..` only vth0 changed while the other four values were written to the CSV but never simulated. Verified on a PMOS and an NMOS: toxe +10 % on its own line changed PMOS ig by -91 % and id by +5 %. Early datasets and results made with the bug are history only; the netlists now use one `altermod` line per parameter (85 lines checked, A1), and A2/A3 above show that every parameter now acts. Source of the before-fix figures: the project log (working notes, not part of the repository, so they are not backed by a saved result file); the after-fix evidence is in the files cited in section 3. ## 6. Models (80:10:10 split, seed 42; model seed 0)

Split: 8,000 training / 1,000 validation / 1,000 test rows per case (one fixed-seed permutation, seed 42) *(source: `ml/config.py, results/analysis/report_numbers/model_facts.txt`)*.
Inputs: 10 varying columns (vdd, temp, w, vd, vs, vth0, toxe, ndep, u0, xj; vg and vb are fixed by the case) plus 10 physics features (vds, |vds|, effective Vgs and Vbs, 1/T, (|Vgs| - |vth0|)/VT, |Vg-Vd|/toxe, |Vg-Vs|/toxe, log10 W, log10(1 - exp(-|Vds|/VT))), standardised on the training split *(source: `ml/pipeline.py: build_features`)*. Target: log10|I| (floor 1e-18 A = abstol) for id, ig, is, ib. Signs restored afterwards (ON: sign(id) = sign(vd - vs); OFF: effective drain has a fixed sign, effective source from a gradient-boosting classifier using the KCL margin) *(source: `pipeline.py: SignModel`)*.

Hyperparameters (from `ml/models.py`): networks trained with Huber loss (beta 0.05 decades) on the standardised log10|I|, AdamW (lr 1e-3, weight decay 1e-4), cosine learning-rate schedule, batch 128, 500 epochs, best-validation-epoch kept. ResNet MLP: Linear(20 -> 256), residual blocks h + Linear(SiLU(Linear(SiLU(h)))) (3 blocks default, 5 chosen for the OFF cases), SiLU, Linear(256 -> outputs); one network per output group (id+is), ig, ib. Hybrid: analytical compact model (EKV channel current with DIBL/body effect, BSIM4-style gate-S/D overlap tunnelling, gate-channel and gate-body tunnelling for ON, reverse junction leakage, GIDL for OFF, body floor; 31 fitted constants for NMOS ON) fitted by least squares on log10|I| + 256-128-64 SiLU MLPs per group on the residual. GPR: exact Gaussian process per current, ARD RBF or Matern-5/2 kernel chosen on validation MAE, hyper-parameters by marginal likelihood on 2,000 random training rows (Adam, 300 steps, float64), conditioned on all 8,000 rows. PINN: 256-128-64 SiLU MLP per group on the raw inputs, Huber loss + Kirchhoff penalty + monotonicity penalty + EKV channel prior for id/is; five physics variants trained together, best per group on validation median error. components_mlp (first model set only): one MLP per BSIM4 current component (needs the internal component currents as labels).
