# archive

Earlier model sets, benchmarks and working files. They are kept as evidence for the report (summary tables, gate-result
CSVs of the first model set and of the benchmark) and are not needed to reproduce the final results. Model binaries
and bulky generated outputs in here are not tracked by git.

| Folder | Contents |
|---|---|
| `first_model_set/` | first model set (70:15:15 split; GPR, hybrid, ResNet, components MLP) and its Part B / Part C results |
| `model_benchmark/` | benchmark of model families, including seed runs |
| `baseline_models/`, `NMOS_ON_models/`, `NMOS_ON_ridge/`, `final_models_2026-11-10/`, `ml_v2_old_scripts/` | earlier experiments |
| `old_work/` | superseded datasets, notebooks and netlists |
