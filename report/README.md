# report

IEEE conference report (IEEEtran). Build: `bash build.sh` (pdflatex + bibtex), result `main.pdf`; the submitted PDF is
`DVD_Angels_Report.pdf`. `make_tables.py` regenerates `tables/*.tex` from the result files; every number in the
text carries a `% src:` comment naming its source file. `EXPERIMENTS_INDEX.md` lists the experiments.
